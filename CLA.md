## How to sign

When you open your first pull request, a bot asks you to sign. Reply in the
pull request with the exact sentence:

> I have read the CLA Document and I hereby sign the CLA

Your GitHub user name, the pull request and the date are recorded in the
`cla-signatures` branch of this repository. One signature covers all your
future Contributions to the Project.
