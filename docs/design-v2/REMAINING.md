## Три диалога в старом виде

Готовый образец для подражания — **менеджер промптов** в текущем `main`
(открывается из меню шапки): две колонки, список слева, редактор справа,
действия относятся к открытому элементу, а не к строке. Классы уже есть в
`styles.css`: `.mgr-columns`, `.mgr-col-list`, `.mgr-col-form`, `.mgr-item`,
`.text-input`, `.btn-dashed`, `.field-head`, `.field-label`.

### 1. Пресеты (`#presets-dialog`)
Та же двухколоночная форма. В строке списка — имя и краткая сводка настроек
(`presetSummary()` в `app.js` уже её строит для меню пилюли). В редакторе:
название, артефакты пилюлями, язык, промпты чекбоксами, «использовать по
умолчанию», внизу — удалить / сохранить.

ВНИМАНИЕ: сценарий `tooltip-icon-buttons` сейчас проверяет паттерн
`[data-tooltip]` именно на кнопках-иконках В СТРОКАХ ЭТОГО диалога — это
последнее место, где они остались. Переделав его, найдите тултипам новый дом
(например, кнопки в шапке карточки), а не ослабляйте проверку.

### 2. Доставка (`#delivery-dialog`)
Двухколоночная форма + **убрать оттуда чекбоксы «Спикеры» и «Не
останавливаться после диаризации»** — они относятся к форме задачи и в диалоге
доставки чужие (замечание Victor'а).

### 3. API-токены (`#tokens-dialog`)
По скриншоту дизайна: строки «имя / префикс · последнее использование» и
кнопка «Отозвать» справа; форма создания снизу одной строкой.

## Известный долг

- **Подсказка персоны в реестре голосов.** Дизайн показывает вторую строку под
  именем («ведёт встречи, быстрая речь»). У модели `Speaker` такого поля нет —
  нужна миграция Alembic + поля в API. Место в вёрстке оставлено.

## Как проверять

```
cd tests/ui && node run.mjs      # 54 сценария, ожидается PASSED
make ui-inventory                # гейт CI: файл генерируемый, руками не править
```

Снять текущий вид для сравнения можно верификатором (см. `tests/ui/harness.mjs`),
но эталон — скриншоты выше, а не то, что получилось.
